## Independent narrow-formula pilot

`bind_width74.py` reconstructs pinned adjacency and crossing-edge
variable IDs without the producer's pin/edge/cut helpers. It emits the
triangle, attachment-degree and window-degree base with the same
sequential-counter order, then enumerates narrow alpha cuts by keeping
eligible vertices in disjoint buckets of optional-edge cost to the
chosen set. Selecting a vertex with bucket cost `j` spends `j` from the
remaining width, drops its forced neighbors, and advances each of its
optional neighbors one bucket. Every unordered forced-independent set
is visited once in increasing order unless its optional-edge count
would exceed three. The code reconstructs the clause at each accepted
leaf, sorts and deduplicates the cuts, and separately checks exact
variable count, exact base prefix, and equality to the ≤3-literal
alpha suffix of the freshly rebound wide CNF. This last check implies
literal inclusion with the same sequential-counter auxiliary variables.

Both six-vertex controls have five literal completions of the
triangle/degree base. With the window independence conditions the
positive control has two completions, the negative none; all 512
optional-edge assignments agree on each side. The negative's weaker
CNF passed CakeLRAT. Each side rejects deletion, duplication and
sign-flip mutations. The standalone binder also regenerated and
CakeLRAT-checked all **14/14** core-5 band residuals on width three.
The narrow formulas total 1,225,925 bytes versus 15,265,658 original
bytes (12.45× smaller). Narrow generation + solve/check 1.27 CPU-s;
standalone inclusion/recheck another 4.88 CPU-s (does **not** price
construction of original references and fallback). This pilot is not
used in the production exclusion; do not extrapolate that all terminal
IDs or other cores will solve in width three.
