Choose for each new vertex an independent old neighborhood hitting every old independent nine. An adjacent pair requires disjoint neighborhoods; a nonadjacent pair must jointly hit every old independent eight. Repeated masks are allowed. For fixed old edges any new forbidden ten uses the new vertex; a second version supports signed cards by checking all ten vertices after mandatory vertical deletions, not just those sets containing the latest pole.

The important new cut is forward-looking. For a fixed independent exterior set `J`, take the union of every old contact still possible at each unassigned vertex of `J`, plus its actual assigned contacts. If the complement contains an old independent set of size `10−|J|`, every descendant fails. It is enough to try the maximal exterior independent sets as a pruning rule; the final physical check is still exact.
