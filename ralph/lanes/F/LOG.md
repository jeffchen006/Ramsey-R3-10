# Lane F experiments

## Round 1: count a whole symmetric orbit flip exactly

**Hand (algorithm identity).** Let `Q` be a pair orbit for a permutation preserving the base graph `H`, with `Q` absent from `H`. Fix one pair `e` in `Q`. Let `a[r]` count independent `k`-sets in `H` containing `e` that contain exactly `r` pairs of `Q`. The change in the count on adding `Q` is `-sum_r |Q|*a[r]/r`: count incidences (pair in `Q`, independent set containing it and exactly `r` orbit-pairs). Every pair contributes `a[r]` by symmetry and every such set contributes `r`; this also proves exact integer division per bin. For deletion, use `H = G - Q` and reverse the sign. This applies at every intermediate orbit boundary of a compound proposal, even if that intermediate graph has triangles.

The patched annealer also preflights triangle repairs: from a triangle-free graph, any new triangle contains an edge of the added orbit. Since the trial graph remains invariant, checking common neighbors of a representative edge suffices. If the other two edges are also in the new orbit, reject. Otherwise remove one of the existing conflict orbits. Deletions cannot make new triangles.

**Rebuild:** `cp anneal/ls.cpp scratch/F/build/sym.cpp; patch scratch/F/build/sym.cpp < ralph/lanes/F/sym.patch; g++ -O3 -march=native -std=c++17 scratch/F/build/sym.cpp -o scratch/F/build/ls_sym`. Use `-w9 0 -symfast -symbatch`, with either `-sym M -symf F` or `-symcycles ...`; `-symverify` computes and compares each whole-orbit delta to the old edge-by-edge update. Logs and exact checkpoint audits are in `scratch/F/r1/`.

**Orbit extension (hand reduction).** For an appended orbit and given internal edge pattern, symmetry dictates the new vertex neighborhoods in the base as `sigma^j(S)`, where `S` is the single unknown subset. `S` must be independent, and where two new vertices are adjacent, their base neighborhoods must be disjoint. For each independent nonempty subset `U` of new vertices and every independent `k-|U|`-set `B` of the base, add the clause requiring `S` to hit `union_{j in U} sigma^{-j}(B)`. This is exactly the condition excluding an independent `k`-set using `U`. Rotating `U` produces the same set of clauses after reindexing all base sets `B`, so one representative suffices. `orbit_extend.py` enumerates each triangle-free internal edge pattern. It uses only `|V(base)|` variables per internal pattern. The reported control and negative target-40 result refer only to their specific input graph and specified permutation.

**Extension seeds:** Random provenance does not prove that a 39-graph is outside Exoo's rewire component. Under exact deduplication, exhausting a seed's own rewire component without its canonical Exoo graph would prove this (valid single-vertex rewires are reversible). The original `k39 bfs` prints “closure complete” even at a finite `maxg` when it stops generating neighbors; do not claim completeness for such capped runs.
