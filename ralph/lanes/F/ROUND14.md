## How one checks a support without signing the card

Use a bit `x_ij` such that physical endpoints `b_i,b_j` at adjacent sites form a **nonedge** exactly when `b_i + b_j = x_ij` over GF(2). Triangle-freeness on a quotient triangle says its three `x` sum to zero. For a set of singleton sites, there is an independent physical transversal iff these equations have a solution in the `b_i`. If independent poles are selected too, forbid their contacted endpoints on the support. If both endpoints of a site are forbidden the support is impossible; if only one is forbidden the other is pinned. Eliminating the `b_i` yields linear equations in the *same* crossing signs for all supports. No choice of crossing signs is made.

If the projected equations are consistent with rank zero, the requested independent set is unavoidable. At rank one, `L=0` would yield a forbidden set, so a target requires `L=1`. Insert that necessary equation and repeat. At higher rank the **indicator** of the forbidden event is `P=product(1+L_j)` for any affine basis of the equations `L_j=0`. On an admissible card all these indicators must be zero. When a listed subset has XOR polynomial identically **one** in the Boolean ring (`x²=x`), not all can vanish. `column_join.cpp` uses component offsets; the Python checker introduces literal endpoint variables and projects them out, then expands indicator products in the original edge variables. This is a finite algebraic receipt, not an LRAT/Lean claim.
