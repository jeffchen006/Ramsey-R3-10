# Deficient paths in R(3): the branch with no common site

A flag `(a,z,b)` means `a,b` is a deficient pair (codegree one) and `z` its unique common neighbor. Assume **every two flags of G intersect as vertex sets**. The following reduction does not infer this from one rooted pair. Write `S=scratch/D/flag12`. The previous D-026 and parity D-023 are used only as explicitly indicated.

**Hand + enum:** under this assumption all flags have a common site. This is not the assertion that all flags have a common *witness*. In fact D-020 and D-026 imply any common site must occur sometimes as an endpoint and sometimes as a centre.

## Abstract incidence cover

For each ordered endpoint-centre arc `(a,z)` there can be only one flag using it: if there were two, the two opposite endpoints would both belong to N(z), would be nonadjacent, and would miss `N(a)−{z}`. These ten vertices cannot be independent. Also the union of all required ordinary edges is triangle-free, and no two flag endpoints may acquire another common neighbor in that union.

If there is *no common site*, fix a flag missing any prescribed site x. Each of its three vertices can occur with x in at most two flags: a nonedge has only one flag using both vertices, and an ordinary edge has at most one in each endpoint-centre direction. Thus x occurs at most six times. This is NOT a bound of six on the total number of flags. `flag_shapes.py` extends one flag by any intersecting triple, retaining the centre, testing the preceding necessary constraints and only this vertex load bound. Each new triple has at most two previously unused sites. Isomorphism is on the ordinary edge union decorated by the flag incidence nodes: the centre is the unique middle in the three-site subgraph. No repeated vertex set represents two flags. At sizes 1…7 there are 1/4/10/15/17/23/0 configurations; the numbers with empty total intersection are 0/0/3/4/1/0/0. See **`S/uncapped/shapes.log`** (six-valence run; not the superseded exploratory three-valence output). Five flags without a common site are the five successive paths on C5.

Independent check `flag_audit.py`: by D-026 choose two flags with disjoint endpoint pairs and different centres; they meet in one or two vertices, giving two seed types. While the intersection is nonempty, choose a flag missing at least one point of that intersection. A final family with no common site always allows such an ordering; after the intersection vanishes, extend by *all* compatible flags. The second procedure uses no flag/vertex bound, stops because no extension exists, and canonicalizes by explicitly permuting flags and reversing endpoints instead of nauty. It recovers two three-flag, four four-flag and one five-flag empty-intersection shapes (it does not include a three-flag shape lacking the D-026 seed). `S/shape-audit.log`. By evenness only the four four-flag types matter. **Exact K=4 is used only here**, not on the common-site branch.

## The mixed common-site branch

Now suppose some one vertex h is on **every** deficient P3. A deficient pair not incident to h must have h as its unique centre. These off-h pairs form a matching in N(h) by the ordered-arc rule, but deficient pairs incident to h are allowed as well. In particular we do **not** use K≤4 or a global matching bound. For reference at most nine deficient pairs have endpoint h (each uses a different incident edge) and at most four have centre h, so K≤13 is valid here; even that total cutoff is not needed. Run bounds 160,9 on global/local defects are loose in this branch.

Take the full D-015 induced kernel P6 cover, 2,434 rooted eight-star profiles. Use **`scratch/D/ind10/six.tsv`**, not the old-ordered `punct8/path.tsv`. Try all eight core sites and one site in each exterior cell as h, retaining h precisely when it meets all forced flags whose endpoints' stars are frozen. Independently undo the coordinate permutation on the original graph: `flag_bindings.py` tests all `2434×40` original labelled sites and matches the same 28,447 inputs (`S/bindings.log`). The exploratory `trans/wrong-order` run is invalid and is not part of any result.

`transversal.cpp`, from D-020's graph engine, requires that a forced singleton path meet its marked set at an endpoint **or its unique possible centre**. For a nonedge with neither endpoint marked, if there is already a mandatory unmarked common neighbor, or no possible marked common neighbor, raise the lower bound to two. Other nonedges still allow codegree one. At a partially constructed row against a frozen star the same rule is applied when at most one final common neighbor can be attained. All ordinary degree, triangle, diameter, independent-set and maximum-codegree rules are unchanged. The marked colour is part of the row-cell partition.

**Conclusion, hand + enum pending review:** a pairwise-intersecting flag family would either have a common site (last table), or have none (four shapes exhausted above). Thus every hypothetical R(3) graph has two **vertex-disjoint deficient P3s**, including their centres. `S/disjoint102.in` is a sufficient 102-root cover, split 60/36/6 by the number of ordinary edges between the four endpoints; it is not an unrooted partition or an exclusion of all internally witnessed markings. It does not prove K≥4. See `PENTAGON.md` for the two-disjoint-pentagons corollary.
