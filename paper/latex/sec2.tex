\section{Preliminaries and published facts used}\label{sec:prelim}

\subsection{Notation}\label{sec:notation}
All graphs are simple. A \emph{$(3,k;n)$-graph} is a triangle-free graph on $n$ vertices with independence number
$\alpha \le k-1$; $R(3,k;n,e)$ is the set of $(3,k;n)$-graphs with $e$ edges (up to isomorphism), and $e(3,k,n)$ is the
least $e$ for which it is non-empty (infinite if empty). A \emph{$(3,10,40)$-graph} $G$ is a $(3,10;40)$-graph; we assume
one exists and derive structure. $d(v)$ is the degree, $n_d$ the number of vertices of degree $d$, $e = e(G)$,
$N(v)$ the neighbourhood, $\Nb{v} = N(v) + v$, and
\[
  \Gv{v} = G - \Nb{v} \quad (39 - d(v) \text{ vertices; also written } H_v \text{ in the notes}), \qquad Z(v) = \sum_{u \in N(v)} d(u).
\]
The \emph{deficiency} is $N = \sum_v (9 - d(v)) = 360 - 2e$. For non-adjacent $u, w$ the \emph{codegree} is
$c(u,w) = |N(u) \cap N(w)|$. $G$ is \emph{maximal triangle-free} (MTF) if adding any edge creates a triangle,
i.e.\ every non-adjacent pair has a common neighbour.

\subsection{Status labels}\label{sec:status}
Every statement in Sections~\ref{sec:structure}--\ref{sec:lean} carries one of these labels.
\begin{itemize}
\item \status{pub} published result, used as a hypothesis (ID in Sec.~\ref{sec:pub}; not re-verified by us).
\item \status{hand} hand proof in this paper, independently re-checked (``CONFIRMED'', with the
  review number in the review log \code{notes/critic.md}; Sec.~\ref{sec:ai}).
\item \status{Lean} proved in Lean~4 / Mathlib, with the published facts it uses as explicit hypotheses (Sec.~\ref{sec:lean}).
\item \status{cert} a computation whose result is checked by a verified checker (exact Farkas certificates in
  rational arithmetic, or SAT proofs checked by cake\_lpr / VeriPB, Sec.~\ref{sec:sat}).
\item \status{enum} an exhaustive enumeration without a proof certificate (gluing runs, Sec.~\ref{sec:glue}).
\item \status{cond: X} proved under the additional hypothesis X.
\end{itemize}

\subsection{Two base facts and their status}\label{sec:basefacts}
The coarse case split (Cover Lemma, Sec.~\ref{sec:cover}) uses only:
\begin{itemize}
\item \textbf{F1}: $e(3,8,m) \ge 6m - 91$ for $23 \le m \le 27$. \status{pub} D-E8 (true values $49, 56, 65, 73, 85 \ge 47, 53, 59,
  65, 71$). In addition \status{cert} for $m = 23, 24, 27$ (SAT, our runs, Sec.~\ref{sec:sat}); $m = 25, 26$ rest on D-E8 only.
\item \textbf{F2}: $R(3,8) \le 28$. \status{pub} D-R2, with the DRAT certificate of \cite{DuLBG}.
\end{itemize}
The refined case tables (Sec.~\ref{sec:open}) also use D-E9 and D-E10b.
