## 1. G: identify the same physical edge in the two shore coordinates (hand + enum + local cert)

**Block.** At the marked adjacent degree-six roots of an MTF `e=170` graph, use G-043: each of the two five-anchor wings has four private sites per anchor and eight distinct double supports among the 28 common exterior sites. Each shore also has one compulsory singleton slot at its deficient coordinate and eight out of ten possible double slots. The two singleton slots are on *different* sites. Neither list of missing doubles is fixed in this experiment.

**New edge representation.** If the left slot `s` mates to the right slot `t`, there is only **one physical vertex** at that pair, not a new graph vertex for each possible mate of `s`. For each grid copy `g`, allocate an edge bit `E_L(s,g)` once for `s` and a bit `E_R(t,g)` once for `t`. A bit on a shore whose supports overlap is the constant false. Use a selector `P(s,t)` for each compatible slot pair, excluding singleton/singleton and pairs that would make a triangle at the crossing. Impose

`P(s,t) ⇒ [E_L(s,g) = E_R(t,g)]` for every grid copy `g`.

Reify slot activity on **both** shores. A slot is active iff it has a selected mate, and has at most one. Require the singleton and exactly eight double slots on each shore. At the crossed coordinate at most three incident double slots can be active: the root, crossing and four private sites already use six of its nine possible neighbours. Every empty noncross cell needs a selected option covering both coordinates (MTF). There is no transpose assumption on a particular board.

Two consequences make this useful:

- **The complete private cell on each shore is now named before the assignment.** It consists of four grid copies or three grid copies and the compulsory singleton slot. In private cells `P_i,P_j` on the same shore, every choice of six sites must contain a crossing edge: otherwise append the other four anchors of the six-vertex root neighbourhood. If the `ij` double exists, it is isolated from both cells, so the same holds for every choice of **five** sites. Enumerate the two subsets of the four actual sites, not sums of presumed matching capacities. The five-site clause needs only `¬active(ij)` as a guard. Both shores' clauses refer to the same physical edges through the conditional equalities.
- **Optional-site blockers no longer allocate an edge for each possible mate.** Reuse the 19 grid sites and the triangle/padded-independent-set rows with at most one chosen option (six-site depth). In a row guarded by `¬P(s,t)`, represent edges from that site to the grid in left-slot coordinates. Keep the shared-support nonedges for its *actual two masks*. For board 4 also require `edge ⇒ active(slot)` and MTF from each grid vertex to each missing wing anchor: the witness is a grid neighbour or a neighbour in a same-shore slot containing that anchor. Omit the row when the opposite crossed endpoint already witnesses the nonedge. These extra clauses have no population variables and no optional/optional edge variables.

**Soundness.** Given a target, label its grid copies and assign every used slot its incident grid edges; give unused slots no edges. The selected mate makes the two descriptions agree. The graph supplies the grid triangles' negative clauses, both private-cell bounds above, and all MTF witnesses. For a padded blocker, choose actual sites and enough independent vertices of the fixed 12-vertex boundary avoiding their supports; if the blocker were false these would be ten independent vertices. `bind_fold.py` reconstructs the symbols separately, enumerates independent subsets of the *literal* boundary and finds a witness for each padded row, including needed sites not named by an edge literal. It checks the complete disjunction for each MTF obligation. Completeness of the relaxation is not required. No order-40 edge-count constraint or solver symmetry assumption enters the six formulas.
