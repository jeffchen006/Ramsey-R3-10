## Main obstacle (my view; please attack it)

In case R all 40 roots see the same class R(3,9;30,99). Choosing a clever root v (or pair, or s-set) helps only if some GLOBAL argument forces an ATYPICAL local configuration to exist; averaging alone only forces configurations at the average, which typical H already have. Every successful reduction so far (Theorem A) used a forced extreme (min e(H_v)), and 9-regularity kills that.
